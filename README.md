# USA-Drug-Overdose_and_Death-Analysis

##  Overview

A Power BI data analysis project exploring drug overdose and death data in the United States to identify trends, patterns, and key indicators through interactive visualizations.

##  Objectives

- Analyze drug overdose and death trends
- Identify patterns across the available data
- Compare key mortality indicators
- Present findings through interactive dashboards

##  Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization

##  Analysis

The dashboard presents key indicators and trends related to drug overdose and mortality data.


##  Skills Demonstrated

Data Analysis • Power BI • DAX • Data Visualization • Exploratory Data Analysis • Dashboard Development
